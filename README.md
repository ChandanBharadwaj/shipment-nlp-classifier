# Shipment Classifier (v3)

Source-driven multi-label classification for free-text shipment descriptions.
Maps cargo / commodity text to a business category (`electronics_electrical`,
`pharmaceuticals`, …) and an HS chapter (`85`, `30`, …).

**v3 design principle:** every runtime artifact (categories, keywords,
centroids) is derived from public sources (US ITC HTS API, UK Trade Tariff
API) plus an LLM with prompts committed to the repo. **No hand-curated rows
in the runtime data path.** `shipment_labels` is used only for F1 evaluation.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the full design.

---

## Quick start

```bash
# 1. Bring up Postgres + pgvector
docker compose up -d

# 2. Apply schema + load 15K labeled rows for evaluation
python init_db.py

# 3. Build the v3 data layer (one-time, then refreshable)
python scripts/fetch_public_data.py              # USITC + UK to local cache (~1 min)
python scripts/load_public_sources.py            # → public_source_descriptions (27K rows)
python scripts/load_llm_categories.py            # → categories (36) + chapter_categories (96)
python scripts/load_llm_cctr.py                  # → keywords (575 anchors/suppressors/modifiers)
python scripts/build_public_keywords.py          # → keywords (6.6K signal-class TF-IDF)
python scripts/validate_chat_cctr.py             # → +1.6K anchors promoted from TF-IDF
python ml-service/centroid_builder.py            # → category_centroids (96)

# 4. Start the classifier API
cd ml-service && venv/Scripts/uvicorn main:app --port 8000

# 5. Build the SPA (one-time)
cd web && npm install && npm run build
```

Open [http://localhost:8000/ui/](http://localhost:8000/ui/) — Bulk Classify,
Overview, Browse, Tokens, Labels, Centroids.

## Refresh data

The pipeline is idempotent. To pull fresh data from upstream:

```bash
python scripts/fetch_public_data.py --force      # re-pull USITC + UK
python scripts/load_public_sources.py            # re-load DB
python scripts/build_public_keywords.py          # re-derive TF-IDF keywords
python scripts/validate_chat_cctr.py             # re-promote unused TF-IDF as anchors
python ml-service/centroid_builder.py            # rebuild centroids
curl -X POST http://localhost:8000/reload        # classifier picks up new state
```

To regenerate categories + CCTR rows via LLM (requires `ANTHROPIC_API_KEY`):

```bash
python scripts/llm_classify_chapters.py          # ~$1, two LLM calls
python scripts/llm_generate_cctr.py              # ~$10-20, 192 LLM calls
```

The chat-substitute CSVs at [data/llm_generated/](data/llm_generated/) cover
the same outputs without an API key — edit the CSVs and re-run the
`load_llm_*` scripts to apply changes.
